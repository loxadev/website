Loxa installation is **still in development**. There is no supported public installer yet.

## Planned installation channels

| Channel | Status | Current instruction |
| --- | --- | --- |
| Bash | Still in development | No supported install command yet. Follow development on [GitHub](https://github.com/loxadev/loxa). |
| npm | Still in development | No supported install command yet. Follow development on [GitHub](https://github.com/loxadev/loxa). |
| Cargo | Still in development | No supported install command yet. Follow development on [GitHub](https://github.com/loxadev/loxa). |
| pip / uv | Still in development | No supported install command yet. Follow development on [GitHub](https://github.com/loxadev/loxa). |
| Homebrew | Coming soon | No supported install command yet. Follow development on [GitHub](https://github.com/loxadev/loxa). |

Installation instructions become actionable only after release artifacts exist and
each path passes clean-machine verification. A separate reviewed change will add an
exact command after that channel passes this boundary.

Read the [current documentation](/docs) or follow the
[public source](https://github.com/loxadev/loxa).
