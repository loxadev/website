Loxa is still in development at version `0.1.0-dev`. The documentation describes
public source state, not a published release.

## Current public status

| Item | Status |
| --- | --- |
| Version | `0.1.0-dev` |
| Development stage | Still in development |
| Platform focus | Apple Silicon first |
| Validation | Manual stress testing in progress |
| Public installers | No supported public installer yet |
| Rust toolchain | Rust 1.96.1 |
| CI | Builds and tests on Ubuntu and macOS Arm64 |
| Project license | Apache License 2.0 |
| Public source | [github.com/loxadev/loxa](https://github.com/loxadev/loxa) |

Current CI covers Ubuntu and macOS Arm64. Windows support is not claimed by the
current public project status.

There is no tagged release or supported public installer yet. See
[Install status](/docs/install) for the planned installation channels.

## License

The Loxa project is licensed under the Apache License 2.0. Model license labels in the
built-in registry are separate metadata for their model artifacts. See
[Models](/docs/models#registry) for those labels.

Experimental branch work is documented separately under
[Experimental supervisor](/docs/experimental/supervisor). It is not part of the
current main branch or a tagged release.
